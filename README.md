# 闪念贝壳 (ideashell) 扩展

在 Raycast / Tinycast 中用**一个输入框**记录一切，并按时间、关键词、Daily Note 回看。通过闪念贝壳官方 MCP 接口（`https://api.ideashell.cn/ideashell/mcp`）与你的笔记同步。

## 命令一览

| 命令 | 模式 | 说明 |
| --- | --- | --- |
| **Smart Capture** | 无界面 | **万能输入**：在根搜索栏输入文字，回车即自动保存为待办 / Daily Note / 笔记 |
| **Notes** | 列表 | **时间线 + 语义搜索 + Daily Note** 合一：输入决定显示什么 |
| **Manage Todos** | 列表 | 按日期分组查看待办，完成 / 恢复 / 编辑 / 新建 |
| **Save Files** | 表单 | 把 Finder 选中的图片 / 音频 / PDF / Office 文件保存为带附件的笔记 |

## 安装与配置

1. 在闪念贝壳 App 中：**设置 → MCP** 获取 API Key。
2. 安装依赖并构建：

   ```bash
   npm install
   npm run build      # 或 npm run dev 进入开发模式
   ```

3. 首次运行任一命令时，在偏好设置中填写：

   | 偏好 | 必填 | 说明 |
   | --- | --- | --- |
   | API Key | 是 | 闪念贝壳 MCP API Key |
   | Daily Note Folder | 否 | Daily Note 所在文件夹，默认 `Daily Notes`。大小写、空格、末尾 `s` 不敏感（`Daily Notes` / `Dailynotes` / `daily-note` 视为同一个）；找不到时自动创建 |
   | Daily Note Title Format | 否 | 预留项，当前 Daily Note 标题固定为 `YYYY-MM-DD` |
   | Default Tags | 否 | 创建笔记时默认附加的标签，逗号分隔 |

### 安装到 Tinycast

Tinycast 的扩展目录为 `~/Library/Application Support/com.tinycast.app/extensions/ideashell`，直接把构建产物输出到该目录即可：

```bash
npx ray build -o "$HOME/Library/Application Support/com.tinycast.app/extensions/ideashell"
```

构建后如未生效，重启 Tinycast。

## Smart Capture 万能输入

在 Tinycast / Raycast 根搜索栏输入 `Smart Capture`（或它的关键词，如「记录」「灵感」），命令会变成输入框左侧的标签，直接输入内容、**回车即保存**，结果通过提示告诉你存到了哪里。

### 三个参数

按 Tab 在参数间切换，**全部可选，默认都是智能识别**：

| 参数 | 说明 |
| --- | --- |
| 正文 | 要记录的内容。**留空**则直接保存剪贴板内容为笔记 |
| 类型（下拉） | `智能识别`（默认）/ `待办` / `Daily Note` / `笔记` / `剪贴板 → 笔记`。手动选择优先级最高 |
| 标签/文件夹 | 如 `#读书 #思考 @阅读笔记`；留空 = 智能识别（取正文里的 `#标签` / `@文件夹`，或正文里出现了某个已有文件夹的名字） |

保存后的提示会说明识别结果，例如「✅ 笔记（智能识别）：…」。

### 标签说明

闪念贝壳 App 只识别**正文末尾的 `#标签`**（不识别接口的 `tags` 字段），所以插件会把标签以 `#标签1 #标签2` 的形式追加到正文最后一行（同时仍传 `tags` 字段）。

### 自动判断

| 输入 | 保存为 |
| --- | --- |
| `明天 15:00 开会`、`下周五交周报`、`10月20日 续费域名`、`20:30 健身` | 待办 |
| `今天试了新的工作流`、`刚想到一个点子` | 追加到今天的 Daily Note |
| `#读书 @阅读笔记 《穷查理宝典》很有启发` | 笔记（带标签，放入「阅读笔记」文件夹） |
| 多行文本，或超过 100 字 | 笔记 |

- 判定为待办的条件：包含**今天及以后的明确时间**（`今天 20:30`），或**明天及以后的日期**。所以「今天试了新的工作流」「昨天 3 点开了会」不会被当成待办。
- `#标签`、`@文件夹` 要求前面是行首或空格（`C#`、邮箱不受影响）；文件夹名同样大小写 / 空格 / 末尾 `s` 不敏感，找不到时会提示并放在未归档。

### 前缀强制指定类型

自动判断不符合预期时，加前缀即可（前缀后可接空格、冒号或逗号）：

| 前缀 | 效果 |
| --- | --- |
| `待办` / `todo` / `提醒我` | 一定存为待办，如 `待办：续费域名`、`提醒我 喝水` |
| `日记` / `daily` | 一定追加到 Daily Note |
| `笔记` / `note` | 一定存为笔记 |

### 使用剪贴板

内容写成 `剪贴板`（或 `clip` / `paste`）表示使用剪贴板里的文字：

- `剪贴板` → 存为笔记
- `日记 剪贴板` → 追加到 Daily Note
- `待办 剪贴板` → 以剪贴板内容创建待办

### 待办的日期时间写法

日期和时间会被自动识别并从内容中去掉：

| 输入 | 结果 |
| --- | --- |
| `明天 15:00 开会` | 内容「开会」，明天 15:00 |
| `下周五下午3点半 交周报` | 内容「交周报」，下周五 15:30 |
| `10月9日 买车票` | 内容「买车票」，10 月 9 日（已过则按明年） |
| `2026-10-20 续费域名` | 内容「续费域名」，指定日期 |
| `周三 洗车` | 本周三（已过则下周三） |
| `20:30 健身` | 只有时间时，日期默认今天 |

支持的写法：

- 日期：`今天/明天/后天/大后天`、`周X / 星期X / 下周X / 下下周X`、`M月D日`、`YYYY-MM-DD`
- 时间：`15:30`、`3点`、`3点半`、`下午3点`、`晚上8点15分`（`下午/晚上` 自动换算为 24 小时制）

### Daily Note 的格式

- 标题为当天日期，如 `2026-10-08`，存放在 Daily Note 文件夹，带 `daily-note` 标签。
- 每次追加一条列表项，时间加粗、精确到分钟：

  ```markdown
  - **2026-10-08 11:57** 开发成功了闪念贝壳
  - **2026-10-08 11:58** 查看今日日记还需要改进
  ```

- 追加时会自动把当天笔记里旧格式（挤在一行、带秒、无列表符号）的条目整理成上述格式。
- 查找今天的笔记时，优先在 Daily Note 文件夹里按标题日期匹配，其次使用本地缓存的 note_id，因此换设备或清缓存也不会重复创建。

## Notes 时间线 · 搜索 · Daily Note

一个列表，**输入的内容决定显示什么**：

| 输入 | 显示 |
| --- | --- |
| （留空） | 最近 7 天时间线：按天分组的待办 + 笔记（每天待办在前），并有可复制的「概览」 |
| `昨天` `上周` `本月` `周三` `上周三` `10月3日` `2026-10-03` `最近14天` `10月1日到10月7日` | 对应时间范围的时间线 |
| `日记`、`日记 上周`、`日记 关键词` | Daily Note 文件夹里的日记，按月分组，可按日期或关键词过滤 |
| 其他文字 | 语义搜索（服务端检索，不按标题二次过滤） |

- 留空时第一行的「快捷入口」也可以直接进入 Daily Note 列表。
- 时间词会优先当作时间范围；想把它当关键词搜索，按 `⌘F`（按关键词搜索）。
- 右侧预览：**标题 → 摘要（引用块）→ 正文**，选中即加载全文；右侧元信息显示创建时间和标签。正文与摘要重复时不重复显示摘要。
- 时间线里的待办可直接回车勾选完成 / 恢复。
- 单次最多回溯 62 天；`recent_notes` 每次最多返回 20 条，插件会自动按时间对半拆分，保证大区间也能取全。待办按其「日期」归入对应的一天，无日期待办不出现在时间线里。

### 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 查看全文 | `↵` |
| 复制整段时间线为 Markdown 回顾（日报 / 周报） | `⌘↵` |
| 复制正文 | `⌘C` |
| 复制摘要 | `⌘⌥C` |
| 复制标题 | `⌘⇧C` |
| 按关键词搜索（而不是当作时间） | `⌘F` |
| 刷新 | `⌘R` |

「复制为 Markdown 回顾」生成的内容可直接贴进日报 / 周报：

```markdown
# 上周 回顾

> 12 条笔记 · 待办完成 5/7

## 2026-10-07 周三

**笔记**

- 15:33 **书法练习 洛神赋** — 今日书法练习，临写赵孟頫行书……

**待办**

- [x] 交周报（15:30）
```

## Manage Todos

- 分组：已逾期 / 今天 / 明天 / 之后每个日期 / 无日期 / 最近已完成（20 条）。
- 快捷键：

  | 操作 | 快捷键 |
  | --- | --- |
  | 标记完成 / 恢复未完成 | `↵` |
  | 编辑待办 | `⌘E` |
  | 新建待办（表单） | `⌘N` |
  | 用搜索栏文字直接创建（同样支持自然语言日期） | `⌘↵` |
  | 复制内容 | `⌘⇧C` |
  | 刷新 | `⌘R` |

- 编辑表单里的日期 / 时间同样支持自然语言（如 `明天`、`下午3点`）。
- 受接口限制，**无法删除待办，也无法清除已设置的日期 / 时间**；编辑时留空表示保持不变。

## Save Files 文件收纳

在 Finder 里选中文件后运行该命令（会自动预填），或在表单里手动选择：

| 类型 | 格式 | 限制 |
| --- | --- | --- |
| 图片 | png / jpg / jpeg / gif / webp | 单张 ≤ 5MB，最多 9 张 |
| 图片（自动转换） | heic / heif / tiff / bmp / avif | 用系统 `sips` 转为 JPEG；超过 5MB 的图片也会自动缩小 |
| 音频 | mp3 / m4a / wav / aac | ≤ 25MB，最多 5 个；**不会自动转写**，需在闪念贝壳 App 里手动发起 |
| 文档 | pdf / doc(x) / xls(x) / ppt(x) | ≤ 50MB，最多 5 个 |
| 文本 | txt / md / csv / log / json / xml / yaml / yml | ≤ 5MB（计入文档的 5 个上限） |

- 服务端会自动提取 **pdf / doc / docx / xls / xlsx / txt / md** 的文字，之后用 Notes 的语义搜索就能搜到文件里的内容；ppt / csv / json 等只存储、不提取文字。
- 超过数量上限时会提示分批保存；单个文件不合规（过大 / 格式不支持）会被跳过并在提示里说明。

## 使用的 MCP 接口

| 接口 | 用途 |
| --- | --- |
| `note_create` / `note_update` / `note_detail` | 创建（含图片 / 音频 / 文档附件）、更新、读取笔记 |
| `note_search` | 语义搜索 |
| `recent_notes` | 最近的笔记（`limit` 1–20）；时间线用它的 `start_time` / `end_time` 区间 |
| `folder_list` / `folder_create` / `folder_notes` | 文件夹列表 / 创建 / 列出文件夹内笔记 |
| `todo_create` / `todo_update` / `todo_list` | 待办的创建 / 更新（含完成状态）/ 查询 |

接口还提供 `unfiled_notes`、`note_move`、`folder_edit`、`speaker_list`、`search_by_speaker`，暂未接入。

## 项目结构

```
src/
├── api.ts               # MCP 客户端 + 笔记 / 文件夹 / 待办 API
├── smart-capture.ts     # Smart Capture 命令（无界面）
├── capture-parse.ts     # 万能输入：前缀、#标签 / @文件夹、类型判断
├── notes.tsx            # Notes 命令（时间线 / 搜索 / Daily Note 合一）
├── timeline-data.ts     # 时间线数据：按天分组、Markdown 回顾
├── time-range.ts        # 时间范围解析（昨天 / 上周 / 10月3日 ……）
├── daily.ts             # Daily Note 文件夹定位、今日笔记查找、追加排版
├── manage-todos.tsx     # Manage Todos 命令
├── todo-parse.ts        # 待办自然语言日期 / 时间解析
├── save-files.tsx       # Save Files 命令
├── attachments.ts       # 附件分类、sips 转换 / 压缩、数量与大小限制
├── note-detail-view.tsx # 笔记全文页（标题 → 摘要 → 正文）
├── use-note-details.ts  # 列表选中时按需加载并缓存笔记全文
└── utils.ts
assets/extension-icon.png
```
