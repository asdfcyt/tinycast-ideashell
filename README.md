# 闪念贝壳 (ideashell) 扩展

在 Raycast / Tinycast 中用**一个输入框**记录一切，并按时间、关键词、Daily Note 回看。通过闪念贝壳官方 MCP 接口（`https://api.ideashell.cn/ideashell/mcp`）与你的笔记同步。

## 命令一览


| 命令                   | 模式       | 说明                                                            |
| -------------------- | -------- | ------------------------------------------------------------- |
| **Smart Capture** | 无界面 | **万能输入**：根搜索栏输入文字回车即自动保存（只弹 HUD，不出现「正在保存」窗口）；什么都不输入回车则打开 Template Capture 的「自由输入」表单 |
| **Template Capture** | 表单       | **模板录入**：按模板填结构化表单（内置 练习 / 阅读 / 决策 / 复盘 / 指标，可自定义），保存为格式固定的笔记 |
| **Clip Selection**   | 无界面      | **摘录**：选中文字 + 浏览器页面标题 / 链接 + 来源应用，一键存成带出处的笔记，可绑全局快捷键          |
| **Notes**            | 列表       | **时间线 + 语义搜索 + Daily Note + 人物 / 主题档案** 合一：输入决定显示什么           |
| **Todos** | 无界面 | **待办入口**：根搜索栏输入内容回车，窗口立即消失，直接创建待办（可带日期时间、`!重要`；不带日期就是无日期待办，在「整理收集箱」里处理；已连接滴答清单则建在滴答）；什么都不输入回车则打开 Todos List |
| **Todos List** | 列表 | **滴答清单为核心**（今天 / 近 7 天 / 逾期）+ 任务笔记 + 项目主页（防弹笔记法） |
| **Todos Menu Bar** | 菜单栏 | **菜单栏待办**：常驻「今天 N · 逾期 M」，点开列出逾期 / 今天的任务，点一下标记完成；后台每 10 分钟刷新 |
| **Save Files**       | 表单       | 把 Finder 选中的图片 / 音频 / PDF / Office 文件保存为带附件的笔记                |


## 安装与配置

1. 在闪念贝壳 App 中：**设置 → MCP** 获取 API Key。
2. 安装依赖并构建：
  ```bash
   npm install
   npm run build      # 或 npm run dev 进入开发模式
  ```
3. 首次运行任一命令时，在偏好设置中填写：

  | 偏好                      | 必填  | 说明                                                                                                              |
  | ----------------------- | --- | --------------------------------------------------------------------------------------------------------------- |
  | API Key                 | 是   | 闪念贝壳 MCP API Key                                                                                                |
  | Daily Note Folder       | 否   | Daily Note 所在文件夹，默认 `Daily Notes`。大小写、空格、末尾 `s` 不敏感（`Daily Notes` / `Dailynotes` / `daily-note` 视为同一个）；找不到时自动创建 |
  | Daily Note Title Format | 否   | 预留项，当前 Daily Note 标题固定为 `YYYY-MM-DD`                                                                            |
  | Default Tags            | 否   | 创建笔记时默认附加的标签，逗号分隔                                                                                               |


### 安装到 Tinycast

Tinycast 的扩展目录为 `~/Library/Application Support/com.tinycast.app/extensions/ideashell`，直接把构建产物输出到该目录即可：

```bash
npx ray build -o "$HOME/Library/Application Support/com.tinycast.app/extensions/ideashell"
```

构建后如未生效，重启 Tinycast。

## 各入口保存什么、存到哪里

闪念贝壳里只有三种东西：**笔记**、**待办**、**Daily Note**（一条以日期为标题、按天追加的特殊笔记）。下表列出每个入口保存的形式。

| 入口 | 保存为 | 标题 | 正文 | 标签 |
| --- | --- | --- | --- | --- |
| Smart Capture（万能输入） | 自动判断：待办 / Daily Note / 笔记（`待办` `日记` `笔记` 前缀可强制） | 笔记：正文首行（≤30 字） | 原文（去掉前缀 / 标签标记） | 正文里的 `#标签` + 默认标签；Daily Note 的标签写在那一条后面 |
| Smart Capture 无参数 / Template Capture 自由输入 | 表单里选的类型（自动识别，可改） | 同上 | 同上 | 表单里的标签 |
| Template Capture（模板） | 一条笔记 | `模板名 日期` | 每项一段 `**字段**：值`，空字段省略 | 模板自带标签 + 默认标签 |
| Clip Selection（摘录） | 一条笔记 | 网页标题，没有则取首行 | 引用块 + 你的批注 + `来源：[标题](链接) · 应用` | `#摘录`（只有页面则 `#收藏`）+ 默认标签 + 你写的标签 |
| Save Files（文件） | 一条带附件的笔记 | 表单标题 | 说明文字或附件名清单 | 默认标签 + 表单标签 |
| **Todos**（根搜索栏带内容） | 一条待办（连接了滴答则建在滴答；不带日期 = 无日期待办） | 待办内容 | — | `!重要` → 高优先级 |
| Todos List：`⌘N` / `⌘↵` | 同上 | 同上 | — | 同上 |
| **项目「记一条」**（`⌘L`，项目行或项目主页） | **一条独立的笔记**（不写入 Daily Note）；内容前写 `待办 …` 则改存为待办；滴答里有与项目**同名的习惯**时自动打卡 | 内容首行（≤30 字） | 你写的内容 | **自动带上该项目的关键词和全部标签**，再加你写的 `#标签`、默认标签；`@文件夹` 可指定文件夹 |
| 任务笔记（`⌘J`） | 一条笔记（一个任务一条） | 交付成果（≤30 字） | 任务 / 交付成果 / 行动目的 / 行动步骤 / 进展记录 / 复盘 | `#任务笔记` + 所属项目关键词；链接会写回滴答任务备注 |
| 任务「记一条进展」（`⌘L`）、`⌘⌥L` 记入专注 | **追加**到该任务笔记的「进展记录」，一行 `- 日期 时间 内容`（精确到分钟）；同时在对应**滴答任务上加一条评论**（`进展：…`） | — | — | — |
| 完成并写复盘（`⌘⇧↵`） | 有任务笔记：写进它的「复盘」小节；没有：另存一条笔记；同时在滴答任务上加一条评论（`复盘：…`） | `完成复盘：任务名` | 复盘内容 | `#复盘` + 所属项目关键词 |
| 项目主页笔记 | 一条笔记（每个项目一条） | `关键词 项目主页` | 目标 / 交付成果 / 任务笔记汇总 / 项目状态 / 资料与链接 / 里程碑与进展 / 复盘与经验 | `#项目主页` + 项目关键词 |
| 完成属于某项目的任务 | **追加**到项目主页笔记的「里程碑与进展」，一行 `- 日期 完成：成果` | — | — | — |

要点：

- **只有 Smart Capture 的「短句」会进 Daily Note**，其余入口都不会往 Daily Note 里写东西；想让一条记录归入某个项目，用项目的「记一条」，或在内容里写 `#项目标签`。
- 项目的归属靠**关键词 / 标签**，所以任何带这些标签的笔记（不论从哪个入口保存）都会出现在该项目的「资料与最近提及」里。
- 「追加」类入口只修改已有笔记的对应小节，不会新建笔记。

## Smart Capture 万能输入

在 Tinycast / Raycast 根搜索栏输入 `Smart Capture`（或它的关键词，如「记录」「灵感」），命令会变成输入框左侧的标签，直接输入内容、**回车即保存**，结果通过提示告诉你存到了哪里。

### 一个参数

只有一个参数「正文」。在里面直接写即可，类型、标签、文件夹都靠**智能识别**，或用前缀 / 标记指定：

- 类型：`待办 …` / `日记 …` / `笔记 …` 前缀强制指定，否则自动判断；
- 标签 / 文件夹：正文里写 `#标签`、`@文件夹`，或正文里出现了某个已有文件夹的名字（自动归入）；
- 正文写成 `剪贴板` 则保存剪贴板内容。

保存后的提示会说明识别结果，例如「✅ 笔记（智能识别）：…」。

### 表单：什么都不输入时

在根搜索栏选中 Smart Capture 后**不输入任何参数直接回车**，会打开 Template Capture 的「自由输入」表单（也可直接运行 Template Capture 选第一项「自由输入」）：在「内容」里输入时，**类型 / 标签 / 文件夹会实时自动填好**（标题带「（自动）」）；手动改过的项不再被自动覆盖，`⌘R` 可全部恢复为自动识别。

### 标签说明

闪念贝壳 App 只识别**正文末尾的** `#标签`（不识别接口的 `tags` 字段），所以插件会把标签以 `#标签1 #标签2` 的形式追加到正文最后一行（同时仍传 `tags` 字段）。

### 自动判断


| 输入                                              | 保存为                 |
| ----------------------------------------------- | ------------------- |
| `明天 15:00 开会`、`下周五交周报`、`10月20日 续费域名`、`20:30 健身` | 待办                  |
| `今天试了新的工作流`、`刚想到一个点子`                           | 追加到今天的 Daily Note   |
| `#读书 @阅读笔记 《穷查理宝典》很有启发`                         | 笔记（带标签，放入「阅读笔记」文件夹） |
| 多行文本，或超过 100 字                                  | 笔记                  |


- 判定为待办的条件：包含**今天及以后的明确时间**（`今天 20:30`），或**明天及以后的日期**。所以「今天试了新的工作流」「昨天 3 点开了会」不会被当成待办。
- `#标签`、`@文件夹` 要求前面是行首或空格（`C#`、邮箱不受影响）；文件夹名同样大小写 / 空格 / 末尾 `s` 不敏感，找不到时会提示并放在未归档。

### 前缀强制指定类型

自动判断不符合预期时，加前缀即可（前缀后可接空格、冒号或逗号）：


| 前缀                    | 效果                          |
| --------------------- | --------------------------- |
| `待办` / `todo` / `提醒我` | 一定存为待办，如 `待办：续费域名`、`提醒我 喝水` |
| `日记` / `daily`        | 一定追加到 Daily Note            |
| `笔记` / `note`         | 一定存为笔记                      |


### 使用剪贴板

内容写成 `剪贴板`（或 `clip` / `paste`）表示使用剪贴板里的文字：

- `剪贴板` → 存为笔记
- `日记 剪贴板` → 追加到 Daily Note
- `待办 剪贴板` → 以剪贴板内容创建待办

### 待办的日期时间写法

日期和时间会被自动识别并从内容中去掉：


| 输入                | 结果                       |
| ----------------- | ------------------------ |
| `明天 15:00 开会`     | 内容「开会」，明天 15:00          |
| `下周五下午3点半 交周报`    | 内容「交周报」，下周五 15:30        |
| `10月9日 买车票`       | 内容「买车票」，10 月 9 日（已过则按明年） |
| `2026-10-20 续费域名` | 内容「续费域名」，指定日期            |
| `周三 洗车`           | 本周三（已过则下周三）              |
| `20:30 健身`        | 只有时间时，日期默认今天             |


支持的写法：

- 日期：`今天/明天/后天/大后天`、`周X / 星期X / 下周X / 下下周X`、`M月D日`、`YYYY-MM-DD`
- 时间：`15:30`、`3点`、`3点半`、`下午3点`、`晚上8点15分`（`下午/晚上` 自动换算为 24 小时制）

### Daily Note 的格式

- 标题为当天日期，如 `2026-10-08`，存放在 Daily Note 文件夹，带 `daily-note` 标签。
- 每次追加一条列表项，时间加粗、精确到分钟：
  ```markdown
  - **2026-10-08 11:57** 开发成功了闪念贝壳
  - **2026-10-08 11:58** 查看今日日记还需要改进
  ```
- 追加时会自动把当天笔记里旧格式（挤在一行、带秒、无列表符号）的条目整理成上述格式。
- 查找今天的笔记时，优先在 Daily Note 文件夹里按标题日期匹配，其次使用本地缓存的 note_id，因此换设备或清缓存也不会重复创建。

## Template Capture 模板录入

把重复的记录变成固定格式：选模板 → 逐项填写 → 保存。命令参数里可直接写模板名（如 `练习`）跳过选择。

- 笔记标题固定为「模板名 日期」（如 `练习 2026-10-08`），正文每项一段 `**字段**：值`，模板自带的标签写在正文末尾（闪念贝壳 App 识别的行内标签），可指定文件夹；空字段自动省略。
- 内置模板：练习（内容 / 自评 / 问题 / 下次）、阅读（书名 / 摘录 / 想法）、决策、复盘、指标。
- 新建模板：在模板列表里按 `⌘N`（每行写一个字段，字段名后加 `+` 为多行），可编辑 `⌘E`、删除 `⌃X`；内置模板可「基于此模板新建」来覆盖。保存在本机，不用改偏好设置。
- 也可在偏好设置 **Templates** 里批量写，多个用 `;` 分隔，语法 `名称:字段1,字段2+,字段3 #标签 @文件夹`（字段名后加 `+` 为多行）。
例：`刻印:作品,印文,感受+,问题+ #篆刻 #练习 @篆刻练习; 体重:体重,备注 #体重`。与内置同名则覆盖内置。

## Clip Selection 摘录

选中任意应用里的文字后运行（建议绑全局快捷键）：

- 保存为一条笔记：标题取网页标题（无则取首行），正文是引用块 + 你的批注 + `来源：[标题](链接) · 应用名`，标签 `#摘录`。
- 浏览器页面（Safari / Chrome / Edge / Brave / Arc / Vivaldi 等）会通过系统脚本读取当前标签页的标题和链接，首次使用需在 **系统设置 → 隐私与安全性 → 自动化** 里允许 Tinycast 控制浏览器；Firefox 无法读取链接，只记录来源应用。
- 没有选中文字但在浏览器里：收藏当前页面（标签 `#收藏`）；都没有则用剪贴板内容。
- 参数里可写批注、`#标签`、`@文件夹`，例如 `这个观点可以用到周报 #读书 @阅读笔记`。

## Notes 时间线 · 搜索 · Daily Note

一个列表，**输入的内容决定显示什么**：


| 输入                                                                   | 显示                                                                                 |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| （留空）                                                                 | 最近 7 天时间线：按天分组的待办 + 笔记（每天待办在前）；顶部「概览」含**今天 / 昨天 / 最近 7 天**三项，各自带分析报告并可复制为 Markdown |
| `档案 张三`、`档案 定价`、`@张三`                                                | **人物 / 主题档案**，见下文                                                                  |
| `回顾`、`随机`                                                            | **往日回顾**：N 周 / 月 / 年前的今天 + 随机一条旧笔记（⌘D 换一条）                                         |
| `昨天` `上周` `本月` `周三` `上周三` `10月3日` `2026-10-03` `最近14天` `10月1日到10月7日` | 对应时间范围的时间线                                                                         |
| `日记`、`日记 上周`、`日记 关键词`                                                | Daily Note 文件夹里的日记，按月分组，可按日期或关键词过滤                                                 |
| 其他文字                                                                 | 语义搜索（服务端检索，不按标题二次过滤）                                                               |


- 留空时第一行的「快捷入口」也可以直接进入 Daily Note 列表或档案。
- **概览分析**（今天 / 昨天 / 任意时间线）：右侧预览分为「元信息」（笔记数与对比、待办完成率、字数、记录时间、高峰时段、每日 / 每周趋势、时段分布、标签榜）和 Markdown 叙述（待办清单含逾期标记、时间轴、自动生成的「观察」）；`⌘↵` 复制的版本还附带完整明细。字数 / 标签基于笔记正文，进入列表后在后台加载（最多 40 条），加载完自动补全。
- 时间词会优先当作时间范围；想把它当关键词搜索，按 `⌘F`（按关键词搜索）。
- 右侧预览：**标题 → 摘要（引用块）→ 正文**，选中即加载全文；右侧元信息显示创建时间和标签。正文与摘要重复时不重复显示摘要。
- 时间线里的待办可直接回车勾选完成 / 恢复。
- 单次最多回溯 62 天；`recent_notes` 每次最多返回 20 条，插件会自动按时间对半拆分，保证大区间也能取全。待办按其「日期」归入对应的一天，无日期待办不出现在时间线里。

### 快捷键


| 操作                            | 快捷键   |
| ----------------------------- | ----- |
| 查看全文                          | `↵`   |
| 复制整段时间线为 Markdown 回顾（日报 / 周报） | `⌘↵`  |
| 复制正文                          | `⌘C`  |
| 复制摘要                          | `⌘⌥C` |
| 复制标题                          | `⌘⇧C` |
| 按关键词搜索（而不是当作时间）               | `⌘F`  |
| 刷新                            | `⌘R`  |


「复制为 Markdown 回顾」生成的内容可直接贴进日报 / 周报：

```markdown
# 上周 回顾

> 12 条笔记 · 待办完成 5/7

## 2026-10-07 周三

**笔记**

- 15:33 **书法练习 洛神赋** — 今日书法练习，临写赵孟頫行书……

**待办**

- [x] 交周报（15:30）
```

关注项（项目）已迁到 **Todos** 命令：Notes 里档案页的 `⌘P` 仍可「钉为项目」，之后在 Todos 的「项目」分区管理。

### 人物 / 主题档案

输入 `档案 名字`（或 `@名字`），把你过往关于某个人、项目、主题的记忆聚合成一页简报，适合见面 / 开会 / 推进前一键回顾：

- **时间脉络**：首次 / 最近提及、累计提及次数、分布天数；
- **近 12 个月提及频率**：迷你柱状图；
- **常伴随的标签**、**最近的提及片段**（带上下文）；
- **相关待办**（未完成 / 已完成）、该说话人的**录音笔记**（通过 `speaker_list` / `search_by_speaker`，名字与联系人匹配时）；
- 下方列出「直接提及」与「可能相关」的笔记，可 `⌘↵` 复制整份简报为 Markdown。

任意笔记的 Actions 里还有「查看『标签』档案」，可从标签直接跳到该主题的档案。简报基于多路语义检索（每路最多 20 条）+ 字面校验，可能不是全部记录。

## Todos（滴答清单 + 任务笔记 + 项目主页）

**入口**：根搜索栏的 `Todos` 带内容回车 = 快速添加待办（例如 `明天 15:00 交报告 !重要`，窗口不闪、直接弹 HUD；不带日期 = 无日期待办，在「整理收集箱」里处理）；不带内容回车 = 打开下面的待办列表（也可直接搜 `Todos List`）。

**不打开也能看到**：
- **根搜索副标题**：输入 `Todos`，命令名旁边显示「今天 3 · 逾期 1 · 下一个 15:00 交报告」。第一次手动运行 `Todos` 后，Tinycast 会每 10 分钟在后台刷新（也可在 Settings → Extensions → Todos → Background refresh 里开关）。
- **菜单栏**：运行一次 `Todos Menu Bar`（或在 Settings → Extensions 里打开它的「Show in menu bar」），菜单栏就常驻「今天 N · 逾期 M」；点开是逾期 / 今天的任务列表，**点一下 = 标记完成**（和列表里一样：清推迟计数、记项目里程碑）。数据来自缓存，打开秒出，后台自动刷新。新增 / 修改了命令后需重启一次 Tinycast。
- **习惯打卡**（菜单栏）：已连接滴答时，菜单里多一个「习惯 · 今天未打卡」小节，只列今天需要打卡的习惯（识别「每周几」重复规则），点一下即打卡（按习惯目标值记为完成）。在项目里「记一条」时，如果滴答里有和项目**同名**的习惯（例如项目「篆刻」、习惯「篆刻」），会自动帮你打卡。习惯接口的原始返回会存在本地缓存（`dida-sample-habits` / `dida-sample-habit_checkins`），解析不对时可据此调整。
- **进展同步到滴答评论**：在任务笔记里「记一条进展」、「完成并写复盘」、「把今日专注记入任务笔记」时，会同时在对应的滴答任务上加一条评论，在滴答 / 手机上也能看到最新进展；失败不影响笔记写入，只对滴答任务生效。

**定位**：以滴答清单的提醒为核心，以闪念贝壳的笔记为辅助，套用「防弹笔记法」——一个任务一条笔记、笔记单位是**交付成果**而不是活动、持续迭代、项目主页统领全局。

- **今天 / 近 7 天 / 逾期**：任务主要从滴答清单拉取（逾期取最近 13 天，近期取未来 7 天，另显示最近完成的 3 条）；闪念贝壳里的待办会并入同一列表。没有日期的任务（滴答收集箱 / 闪念贝壳）不显示在列表里，统一在**整理收集箱**（`⌘⇧I`）里逐条处理：定日期、归入项目、写交付成果、完成、删除。「最近已完成」按完成时间排序，与有没有日期 / 时间无关。
- **视图**：`⌘Q`（或 Actions 里的「切换视图」；下拉框会占用 `⌘P`，已去掉），在「时间视图」（已逾期 / 今天 / 明天 / 之后每一天 / 最近已完成）与「四象限视图」间切换。重要 = 滴答高优先级（或 `!重要`），紧急 = 今天 / 明天 / 已逾期，或 `!紧急`。
- **任务行一览**：有任务笔记的任务，副标题显示「→ 交付成果」，右侧直接显示笔记正文；没有任务笔记的显示灰色问号，提醒你先想清楚要交付什么。
- **推迟预警**：任务被推迟 3 次以上会标橙色「重复」图标，并提示拆小任务、补写交付成果。
- **专注（番茄钟）**：滴答的 MCP 只能读写专注**记录**，不能启动计时，所以计时在滴答里进行：任务上按 `⌘P` 触发 macOS 快捷指令「滴答开始专注」（放在「标记完成」后面）。回到 Todos 后，任务右侧显示「今日 / 近 7 天专注时长」，滴答清单分区有「专注」汇总（按任务），项目主页显示相关任务的近 7 天专注，`⌘⌥L` 可把今日专注记入任务笔记的「进展记录」。
  - 快捷指令设置：新建名为 **滴答开始专注** 的快捷指令，动作依次为「滴答清单 → 开始专注（番茄 / 25 分钟）」，再加一个「运行 Shell 脚本」：`osascript -e 'tell application "System Events" to set visible of process "TickTick" to false'`，让滴答开始计时后自动隐藏、不打断当前窗口（滴答的该动作必须启动 App，无法完全避免）。
- **任务笔记**（`⌘J`）：为任务创建一条笔记，必须先写清「交付成果」，并带有 行动目的 / 行动步骤 / 进展记录 / 复盘 结构；笔记链接会写回滴答任务的备注。已有任务笔记时 `⌘J` 直接打开，`⌘L` 往里追加一条进展。
- **完成并写复盘**（`⌘⇧↵`）：完成任务并把复盘写进任务笔记（没有则另存一条 `#复盘` 笔记）。
- **项目**（原关注项）：用关键词 + 标签定义长期在做的事，显示「N 天没碰了」、近 30 天次数、迷你图、手写**下一步**、相关任务。回车进入**项目主页**：项目主页笔记（目标 / 交付成果 / 任务笔记自动汇总 / 资料 / 里程碑 / 复盘；`⌘R` 一键更新「任务笔记汇总」（每个成果的状态 / 步骤进度 / 近 7 天专注）和「项目状态」（下一步 / 成果进度 / 专注），内容直接显示在右侧；完成属于该项目的任务时自动在「里程碑与进展」追加一行）、要交付的成果（任务笔记）、滴答里的相关任务、资料与最近提及。
  - 添加：`⌘⇧P`，填关键词，再从闪念贝壳已有标签里**多选**；或 Notes 档案页 `⌘P`。`⌘T` 修改项目标签。
  - 任务归属项目：任务标题含项目关键词，或任务标签含项目关键词 / 标签。
- **快捷键**：

  | 操作 | 快捷键 |
  | --- | --- |
  | 标记完成 / 恢复未完成 | `↵` |
  | 完成并写复盘 | `⌘⇧↵` |
  | 创建 / 打开任务笔记 | `⌘J` |
  | 记一条进展（任务 / 项目） | `⌘L` |
  | 编辑待办 / 设置项目下一步 | `⌘E` |
  | 新建待办（表单） | `⌘N` |
  | 用搜索栏文字直接创建 | `⌘↵` |
  | 标记重要 / 紧急（紧急仅闪念待办） | `⌘I` / `⌘U` |
  | 推迟到明天 | `⌘⇧T` |
  | 在滴答中打开 | `⌘O` |
  | 开始专注（快捷指令） | `⌘P` |
  | 把今日专注记入任务笔记 | `⌘⌥L` |
  | 新增项目 | `⌘⇧P` |
  | 整理收集箱（无日期任务） | `⌘⇧I` |
  | 项目：查看档案 | `⌘D` |
  | 切换时间 / 四象限视图 | `⌘Q` |
  | 立即同步滴答清单 | `⌘⇧S` |
  | 刷新 | `⌘R` |

- 日期 / 时间支持自然语言（如 `明天`、`下午3点`）。闪念贝壳接口无法删除待办，也无法清除已设置的日期 / 时间。

### 连接滴答清单

通过滴答清单官方 MCP（[说明](https://help.dida365.com/articles/7438132116019216384)）。连接后：新建待办直接创建在滴答（有时间：准点提醒；仅日期：当天 9:00 提醒）；完成 / 改期 / 改优先级直接改滴答；闪念贝壳里带日期的待办自动同步到滴答；在滴答里完成的，下次打开时带回。删除不会同步。未连接时只显示闪念贝壳的待办。

连接（一次即可）：网页版滴答清单 → 头像 → 设置 → 账户与安全 → **API 口令** → 创建并复制；然后在 Todos 底部「连接滴答清单」里粘贴。口令只保存在本机。

## Save Files 文件收纳

在 Finder 里选中文件后运行该命令（会自动预填），或在表单里手动选择：


| 类型       | 格式                                             | 限制                                        |
| -------- | ---------------------------------------------- | ----------------------------------------- |
| 图片       | png / jpg / jpeg / gif / webp                  | 单张 ≤ 5MB，最多 9 张                           |
| 图片（自动转换） | heic / heif / tiff / bmp / avif                | 用系统 `sips` 转为 JPEG；超过 5MB 的图片也会自动缩小       |
| 音频       | mp3 / m4a / wav / aac                          | ≤ 25MB，最多 5 个；**不会自动转写**，需在闪念贝壳 App 里手动发起 |
| 文档       | pdf / doc(x) / xls(x) / ppt(x)                 | ≤ 50MB，最多 5 个                             |
| 文本       | txt / md / csv / log / json / xml / yaml / yml | ≤ 5MB（计入文档的 5 个上限）                        |


- 服务端会自动提取 **pdf / doc / docx / xls / xlsx / txt / md** 的文字，之后用 Notes 的语义搜索就能搜到文件里的内容；ppt / csv / json 等只存储、不提取文字。
- 超过数量上限时会提示分批保存；单个文件不合规（过大 / 格式不支持）会被跳过并在提示里说明。

## 使用的 MCP 接口

### 闪念贝壳（`https://api.ideashell.cn/ideashell/mcp`）

| 接口 | 用途 |
| --- | --- |
| `note_create` / `note_update` / `note_detail` | 创建（含图片 / 音频 / 文档附件）、更新、读取笔记 |
| `note_search` | 语义搜索 |
| `recent_notes` | 最近的笔记（`limit` 1–20）；时间线用它的 `start_time` / `end_time` 区间 |
| `folder_list` / `folder_create` / `folder_notes` | 文件夹列表 / 创建 / 列出文件夹内笔记 |
| `speaker_list` / `search_by_speaker` | 说话人列表 / 按说话人检索录音笔记（人物档案） |
| `todo_create` / `todo_update` / `todo_list` | 待办的创建 / 更新（含完成状态）/ 查询 |

接口还提供 `unfiled_notes`、`note_move`、`folder_edit`，暂未接入。

### 滴答清单（`https://mcp.dida365.com`）

Streamable HTTP，`Authorization: Bearer <API 口令>`，会话用 `Mcp-Session-Id`。

| 接口 | 用途 |
| --- | --- |
| `initialize` / `notifications/initialized` / `tools/list` | 建立会话；连接时读取并缓存工具清单 |
| `list_projects` | 读取清单名称（显示「收集箱」等） |
| `list_undone_tasks_by_date` | 按日期区间拉取未完成任务（逾期近 13 天、今天起 7 天；单次最多 14 天） |
| `list_undone_tasks_by_time_query` | 按 `today` / `next7day` 拉取未完成任务（与上一项合并去重，补漏全天任务） |
| `get_project_with_undone_tasks` | 读取收集箱（`inbox`）的未完成任务，取没有日期的（整理收集箱） |
| `delete_task` | 在整理收集箱里删除滴答任务 |
| `list_completed_tasks_by_date` | 拉取最近 3 天已完成任务 |
| `create_task` | 新建任务（参数需放在 `task` 内）；同步闪念贝壳里带日期的待办 |
| `update_task` | 修改标题 / 日期 / 时间 / 优先级 / 备注；恢复为未完成 |
| `complete_task` | 完成任务 |
| `get_focuses_by_time` | 读取近 7 天的专注（番茄钟 / 正计时）记录，显示专注时长 |
| `get_task_by_id` | 同步时核对任务状态（在滴答里完成的带回）；查任务所在清单（写评论用） |
| `list_habits` | 读取习惯列表（菜单栏打卡、项目同名习惯） |
| `get_habit_checkins` | 读取今天的习惯打卡情况 |
| `upsert_habit_checkins` | 给习惯打卡 |
| `add_comment` | 把任务笔记里的进展 / 复盘同步成滴答任务评论 |
